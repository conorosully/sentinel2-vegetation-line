# sentinel2-vegetation-line
Detecting sub-pixel changes in the coastal vegetation line with Sentinel-2 imagery

This repository contains the code required to reproduce the results in the journal paper:

> C. O'Sullivan, X. Monteys and S. Dev, "Detecting Subpixel Changes in the Coastal Vegetation Line With Sentinel-2 Imagery," in IEEE Journal of Selected Topics in Applied Earth Observations and Remote Sensing, vol. 19, pp. 10421-10437, 2026, doi: 10.1109/JSTARS.2026.3661632. [available here](https://ieeexplore.ieee.org/abstract/document/11372985).

and this conference paper: 

> coming soon

This code is only for academic and research purposes. Please cite the above paper if you intend to use whole/part of the code.

## Code Files
- `demo.ipynb` demonstration of the best SimpleCNN model. 
- `get_combined_pred_demo.gif` animation of combined predictions generated by `demo.ipynb`.
  
You can find the following files in the src folder:

- `0_process_rasters.ipynb` Stack Sentinel-2 scenes, Guidance band and vegetation lines so they can be used to create a modelling dataset.
- `0_process_rasters_erosion.ipynb` Process Sentinel-2 scenes so they can be used to calculate erosion rates.
- `1_create_model_dataset.ipynb` Create training and test data for edge detection machine learning models.
- `2_model_evaluation.ipynb` Produce metrics and visualisations for the performance of all edge detection models.
- `3_calculate_average_lines.ipynb` Calculate the average detected vegetation line (AVDLs) and format results for DSAS, for Bull Island.
- `3_calculate_average_lines_portmarnock.ipynb` Calculate the AVDLs and format results for DSAS, for Portmarnock.
- `3_calculate_probalistic_lines.ipynb` Calculate probabilistic detected vegetation lines and format results for DSAS.
- `4_compare_erosion_rates.ipynb` Visualise and summarise the erosion rates and distance calculations from DSAS.
- `4_compare_erosion_rates_pl.ipynb` Visualise and summarise the erosion rates and distance calculations from DSAS, using the probabilistic lines.
- `5_figures_for_paper.ipynb` Additional figures for research paper
- `6_alternative_aggregation.ipynb` Explore an alternative method for aggregating combined predictions.
- `utils.py` Helper functions used to perform the analysis. 
- `evaluation.py` Help functions used to evaluate the edge detection models.
- `line_processing.py` Helper functions for connecting and processing detected edge/line pixel maps.
- `network_hed.py` Holistic nested edge detection architecture and backbones.
- `train.py` Training loop and hyperparameter testing.
